# ZoneRunner Privacy Policy

Last updated: 2025-12-16

## What we collect
- Account info: email, display name, optional username, avatar/banner color, and optional profile details you add (height, weight, gender, birth date, phone).  
- Location data: precise GPS location while you are actively recording a run (including background if you opt in so a run keeps recording when the screen locks).  
- Run metrics: distance, time, route coordinates, area captured, and group run membership.  
- Device-stored caches: temporary run fragments saved locally to keep tracking smooth between app launches.

## Why we collect it
- Run tracking: map your path, calculate distance/pace/area, and determine territory ownership.  
- Account and groups: create and manage your profile, join groups, and show territory colors and stats.  
- Reliability: temporarily cache run data so it can be saved even if the app is backgrounded during an active run.

## How we use and share data
- We do **not** sell your data.  
- We do **not** use third-party advertising or cross-app tracking.  
- Data is used only to provide ZoneRunner features. Group runs share run stats with the selected group; nothing is shared beyond that unless you choose to.

## Storage and retention
- Account profiles and saved runs are stored securely in our cloud database.  
- Temporary background run caches are stored on your device and cleared when a run ends.  
- You can delete your account to remove profile and run data from our servers; cached device data is cleared automatically.

## Your choices
- Location access is requested only for running features. Background location is optional and used only while a run is active.  
- You can manage location permissions in system settings and can stop runs at any time.  
- Contact us to access, update, or delete your data.
